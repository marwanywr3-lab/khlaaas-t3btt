## تشغيل النسخة الحالية

افتح `index.html` في المتصفح مع إبقاء مجلد `assets` بجانبه، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`. تعتمد النسخة الأصلية على Tailwind CDN وخطوط Google، لذا يلزم اتصال بالإنترنت لتحميلهما.

## المرحلة الأولى: المظهر والخلفية

- تحويل المظهر الداكن إلى أوراق بيج، نص بني واضح، حدود هادئة وأزرار بلون وردي بني.
- استخدام صورة مكتب التحقيق الأفقية كخلفية رئيسية والصورة العمودية للشاشات الصغيرة.
- إضافة `assets/theme.css` المشتركة للصفحة المباشرة ومكوّن React.
- إزالة نص HTML زائد كان يظهر بعد نهاية الصفحة.

## المرحلة الثانية: الاستجابة للشاشات والشريط الجانبي

- زر القائمة ظاهر على الجوال والحاسوب، ويفتح سجلاً جانبياً يمين الشاشة يمكن إغلاقه بزر أو بالنقر خارجه أو بمفتاح Escape.
- الشريط مخفي عند بدء التشغيل، ولا يحجز مساحة من منطقة التحقيق.
- ثلاث لوحات متزامنة للشاشات بعرض 1440 بكسل أو أكثر؛ تبويبات مستقلة للعرض الأقل، لتجنب ضغط مساحة التحقيق.
- نسخة واحدة من كل لوحة، لتجنب تكرار حقول الإدخال عند تغيير حجم النافذة.
- تحسين ارتفاع الشاشة الديناميكي، حجم حقول الهاتف، مساحة الإيماءات، وتمرير النوافذ عند قلة الارتفاع.
- تطبيق التعديلات على الصفحة المباشرة ومصادر React.

## المرحلة الرابعة: العربية والإنجليزية

- إضافة زر English / العربية أعلى الواجهة، وحفظ اختيار اللغة محلياً.
- تبديل اتجاه العرض RTL / LTR مع بقاء القائمة الجانبية على اليمين.
- ترجمة الأزرار والعناوين والإعدادات والحقول في الصفحة المباشرة ومكوّنات React.
- توجيه النموذج لإنشاء القضايا وإرسال الردود الجديدة باللغة المختارة، مع إبقاء مفاتيح JSON ومعرّفات الخيارات ثابتة.
- إبقاء السجل والأسماء والملاحظات المكتوبة كما هي، والحفاظ على المدخلات عند تبديل اللغة.

## المدخلات والترحيب والمستشار

- حفظ مسودات التحقيق والاستشارة وفكرة القضية ولائحة الاتهام محلياً، مع فصل مسودات كل قضية عن الأخرى.
- الاحتفاظ بالنص عند فشل الطلب، ومسح النص المُرسل فقط بعد نجاح الرد دون مسح نص أحدث.
- بدء الاستخدام دون قضية تجريبية مدمجة، مع إبقاء القضايا التي أنشأها المستخدم.
- إظهار «أهلاً بك يا محقق» مرة واحدة عند فتح القضية، ومنع تكرار الترحيب في ردود المستشار التالية بتعليمات النموذج وتنظيف بادئة الرد.
- إضافة زر أعلى المستشار للتبديل بين الدعم القانوني ودعم التحقيق العملي، دون كشف الحل السري.
- تغيير اسم المستشار من الإعدادات، وحفظ الاسم والنمط محلياً مع دعم العربية والإنجليزية.

هذه النسخة تشمل المراحل السابقة، مع تجاوز المرحلة الثالثة بطلب المستخدم. أُنجزت سيناريوهات التعديل الخامس وموازنة مدة القضايا في التحديث الأخير أدناه. في مرحلة التصميم الأولى لم تُغيّر بيانات القضايا أو إعدادات API.

مجلد `src` المرفق هو مصدر React الأصلي، ولا يحتوي الأرشيف الأصلي على إعداد بناء أو `package.json`. الصفحة المباشرة `index.html` هي نقطة التشغيل المتاحة حالياً.

## تحديث الخلفية بحسب الجهاز

الصورة الطولية للجوال حتى عند تدويره، والصورة العرضية للحاسب والتابلت حتى عندما يكون التابلت بالطول. يُحدّد النوع من معلومات الجهاز، وليس من عرض نافذة المتصفح وحده. تُستخدم أبعاد الشاشة واللمس كبديل للأجهزة التي لا تعرّف نوعها. تبقى الخلفية العرضية هي الافتراضية عند تعطيل JavaScript. تم تطبيق التغيير على الصفحة المباشرة ومصدر React.

### النشر على GitHub Pages
1. فك ZIP وافتح مجلد Arrest-the-accused-AtA--main.
2. في المستودع افتح Add file ثم Upload files وارفع ملف index.html الموجود داخل المجلد، ليحل محل index.html في جذر المستودع. لا ترفع مجلدًا جديدًا داخل المستودع.
3. اضغط Commit changes وانتظر اكتمال النشر. في Settings > Pages يكون المصدر هو الفرع المستخدم والمجلد / (root).
4. حجم index.html الصحيح أكثر من 2 MB، ومحتواه يبدأ بتعريف HTML. إذا كان فارغًا لم يتم رفع الملف الصحيح.
5. افتح الموقع وحدّثه بعد اكتمال النشر. لا تحتاج حذف ملفات JSX أو JS السابقة أو إعادة إدخال المفتاح.
